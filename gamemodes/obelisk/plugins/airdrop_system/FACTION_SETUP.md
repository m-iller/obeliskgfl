# Настройка фракций - Краткая инструкция

## Важно!
**Плагин НЕ использует флаги!** Весь доступ основан на ID фракции персонажа.

## Шаг 1: Узнайте ID фракций

### Способ 1: Консоль сервера
1. Зайдите в игру как администратор
2. Нажмите F3 или ~ чтобы открыть консоль
3. Введите: `lua_run PrintTable(ix.faction.teams)`
4. Запишите ID нужных фракций

### Способ 2: Файлы схемы
Откройте файлы в `gamemodes/obelisk/schema/factions/`

Пример из `sh_citizen.lua`:
```lua
FACTION.name = "Citizen"
FACTION.description = "Обычный гражданин"
-- И далее в файле:
FACTION_CITIZEN = FACTION.index
```

Обычно ID фракций:
- `FACTION_CITIZEN = 1`
- `FACTION_MPF = 2`
- `FACTION_OTA = 3`
- `FACTION_ADMIN = 4`
- И т.д.

## Шаг 2: Настройте конфигурацию

Откройте `gamemodes/obelisk/schema/configuration/sh_airbrop.lua`

### Базовый пример:

```lua
factions = {
    faction1 = {
        name = "Повстанцы",
        factionID = 1,  -- Только персонажи с ID фракции = 1 могут использовать терминал
        allowedTargetFactions = {1, 3, 5},  -- Можно вызывать аирдроп на игроков с ID фракций 1, 3 или 5
        
        airdrops = {
            {
                type = "small_supply",
                name = "Малый грузовой аирдроп",
                description = "Небольшой ящик с боеприпасами",
                entityClass = "sw_airdrop_v3",
                maxActive = 3,
                spawnHeight = 1000,
                lifetime = 1800
            }
        }
    },
    
    faction2 = {
        name = "Альянс",
        factionID = 2,
        allowedTargetFactions = {2, 3},
        
        airdrops = {
            {
                type = "small_supply",
                name = "Малый грузовой аирдроп",
                description = "Небольшой ящик с боеприпасами",
                entityClass = "sw_airdrop_v3",
                maxActive = 3,
                spawnHeight = 1000,
                lifetime = 1800
            }
        }
    }
}
```

### Расширенный пример (несколько фракций):

```lua
faction1 = {
    name = "Сопротивление",
    factionID = {1, 3, 5},  -- Несколько фракций могут использовать этот терминал
    allowedTargetFactions = {1, 3, 5, 7, 9},  -- Большой список целей
    
    airdrops = {
        {
            type = "small_supply",
            name = "Малый грузовой аирдроп",
            description = "Небольшой ящик с боеприпасами",
            entityClass = "sw_airdrop_v3",
            maxActive = 3,
            spawnHeight = 1000,
            lifetime = 1800
        },
        {
            type = "large_supply",
            name = "Большой грузовой аирдроп",
            description = "Крупный контейнер с припасами",
            entityClass = "sw_airdrop_large_v3",
            maxActive = 2,
            spawnHeight = 1200,
            lifetime = 2400
        }
    }
}
```

## Параметры конфигурации

### `factionID`
- **Тип:** число или массив чисел
- **Описание:** ID фракции (или фракций), чьи персонажи могут использовать терминал
- **Примеры:**
  - `factionID = 1` - только одна фракция
  - `factionID = {1, 2, 3}` - несколько фракций

### `allowedTargetFactions`
- **Тип:** массив чисел
- **Описание:** ID фракций, чьих игроков можно выбирать как цель для вызова аирдропа
- **Пример:** `allowedTargetFactions = {1, 3, 5}`

## Проверка настройки

1. Зайдите на сервер персонажем нужной фракции
2. Подойдите к терминалу
3. Нажмите E
4. Если видите сообщение "Доступ запрещён" - проверьте `factionID`
5. Если при выборе "На игрока" список пуст - проверьте `allowedTargetFactions`

## Частые ошибки

### Ошибка 1: "Доступ запрещён"
**Причина:** Персонаж не принадлежит к фракции из `factionID`
**Решение:** Проверьте ID фракции персонажа и сравните с конфигом

### Ошибка 2: "Нет доступных игроков"
**Причина:** На сервере нет игроков из фракций `allowedTargetFactions`
**Решение:** Зайдите вторым персонажем нужной фракции или добавьте больше фракций в список

### Ошибка 3: Константы FACTION_* не найдены
**Причина:** Константы не определены в момент загрузки конфига
**Решение:** Используйте числовые ID вместо констант:
```lua
factionID = 1  -- вместо FACTION_CITIZEN
```

## Добавление нового терминала для третьей фракции

1. Скопируйте `ix_ads_faction1_terminal.lua` в `ix_ads_faction3_terminal.lua`
2. Измените в новом файле:
   - `PrintName = "Консоль вызова аирдропов (Фракция 3)"`
   - `local factionKey = "faction3"`
3. Добавьте в `sh_airbrop.lua`:
```lua
faction3 = {
    name = "Третья фракция",
    factionID = 4,
    allowedTargetFactions = {4},
    airdrops = { ... }
}
```

## Тестирование

1. Создайте персонажа нужной фракции
2. Заспавните терминал
3. Попробуйте использовать
4. Проверьте список игроков при выборе "На игрока"
5. Попробуйте вызвать аирдроп
6. Проверьте консоль на ошибки (F3)
