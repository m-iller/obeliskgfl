# Быстрая установка Airdrop System

## Шаг 1: Проверка файлов

Убедитесь что у вас есть:
- ✅ `gamemodes/obelisk/plugins/airdrop_system/` - плагин
- ✅ `gamemodes/obelisk/plugins/airdrope/` - материалы и энтити аирдропов
- ✅ `gamemodes/obelisk/schema/configuration/sh_airbrop.lua` - конфигурация

## Шаг 2: Перезапуск сервера

1. Перезапустите сервер
2. Плагин автоматически загрузится при старте

## Шаг 3: Установка терминалов

1. Зайдите на сервер как администратор
2. Откройте меню спавна энтити
3. Найдите категорию "Airdrop System"
4. Установите терминалы:
   - `ix_ads_faction1_terminal` - для первой фракции
   - `ix_ads_faction2_terminal` - для второй фракции

## Шаг 4: Настройка фракций

**ВАЖНО: Плагин НЕ использует флаги!**

1. Откройте `gamemodes/obelisk/schema/configuration/sh_airbrop.lua`
2. Найдите ID ваших фракций (они определены в `schema/factions/`)
3. Настройте `factionID` для каждого терминала
4. Настройте `allowedTargetFactions` - какие фракции можно выбирать как цель

**Как узнать ID фракций:**
- Зайдите в игру как админ
- Откройте консоль (F3 или ~)
- Введите: `lua_run PrintTable(ix.faction.teams)`
- Найдите нужные фракции и их ID

**Пример настройки:**
```lua
faction1 = {
    name = "Повстанцы",
    factionID = 1,  -- ID фракции CITIZEN
    allowedTargetFactions = {1, 3},  -- Можно вызывать на CITIZEN и MEDIC
    ...
}
```

## Шаг 5: Настройка (опционально)

Отредактируйте `sh_airbrop.lua` для настройки:
- Названий фракций
- Кулдаунов
- Типов аирдропов
- Лимитов
- Высоты спавна

## Готово!

Игроки нужных фракций теперь могут:
1. Подойти к терминалу своей фракции
2. Нажать E для взаимодействия
3. Выбрать тип аирдропа
4. Выбрать цель (позиция или игрок из разрешенных фракций)
5. Вызвать аирдроп

## Проблемы?

- **"Доступ запрещён"** - проверьте `factionID` в конфиге, персонаж должен быть из этой фракции
- **"Нет доступных игроков"** - проверьте `allowedTargetFactions`, на сервере нет игроков из этих фракций
- **Не видно энтити** - убедитесь что папка `airdrope` на месте
- **UI не открывается** - проверьте консоль на ошибки (F3 или ~)
- **Аирдроп не спавнится** - проверьте лимиты в конфиге или консоль на ошибки
- **Не знаю ID фракций** - используйте команду `lua_run PrintTable(ix.faction.teams)` в консоли сервера
