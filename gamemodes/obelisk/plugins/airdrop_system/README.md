# Airdrop System - Система вызова аирдропов для Helix Framework

## Описание
Полноценная система вызова аирдропов с терминалами для двух фракций. Позволяет вызывать различные типы аирдропов как на конкретную позицию, так и на игрока.

## Возможности
- ✅ Система для нескольких фракций с отдельными терминалами
- ✅ Система доступа по фракции персонажа (БЕЗ флагов!)
- ✅ **Заготовленные позиции для вызова** - никакого тыканья по карте!
- ✅ Вызов аирдропа на заранее настроенную позицию или на игрока
- ✅ Выбор игроков только из определенных фракций
- ✅ **Поддержка нескольких фракций на один терминал**
- ✅ Кулдауны между вызовами
- ✅ Лимиты активных аирдропов
- ✅ Современный UI интерфейс
- ✅ Автоматическое удаление через указанное время
- ✅ RP отыгрывание при использовании терминала
- ✅ Команда `/getposentity` для получения координат

## Конфигурация

Все настройки находятся в `sh_airbrop.lua`:

### Основные параметры
- `cooldown` - кулдаун между вызовами (в секундах)
- `defaultLifetime` - время жизни аирдропа по умолчанию (0 = бесконечно)

### Настройка фракций

```lua
factions = {
    faction1 = {
        name = "Повстанцы",                         -- Название фракции
        factionID = FACTION_CITIZEN,                -- ID фракции для доступа к терминалу
                                                    -- Можно указать одну: FACTION_CITIZEN
                                                    -- Или несколько: {FACTION_CITIZEN, FACTION_OTA}
        allowedTargetFactions = {FACTION_CITIZEN},  -- ID фракций игроков для выбора как цель
        
        -- Заготовленные позиции для вызова аирдропов
        positions = {
            {
                name = "Площадь центра города",
                pos = Vector(0, 0, 0)  -- Используйте /GetPos для получения координат
            },
            {
                name = "Склады",
                pos = Vector(100, 200, 50)
            }
        },
        
        airdrops = {
            {
                type = "small_supply",          -- Уникальный ID типа
                name = "Малый грузовой аирдроп", -- Отображаемое название
                description = "Описание",       -- Описание
                entityClass = "sw_airdrop_v3",  -- Класс энтити
                maxActive = 3,                  -- Макс. активных одновременно
                spawnHeight = 1000,             -- Высота спавна над целью
                lifetime = 1800                 -- Время жизни (0 = бесконечно)
            }
        }
    }
}
```

**Важно:** ID фракций определены в вашей схеме (обычно в `schema/factions/`). Например:
- `FACTION_CITIZEN = 1`
- `FACTION_MPF = 2`
- `FACTION_OTA = 3`

Чтобы узнать ID фракций, введите в консоль сервера: `lua_run PrintTable(ix.faction.teams)`

## Использование

### Для администраторов

1. **Настройка позиций:**
   - Встаньте в нужное место на карте
   - Откройте консоль и введите `/getposentity`
   - Скопируйте координаты и добавьте в `sh_airbrop.lua` в секцию `positions`

2. **Установка терминалов:**
   - Спавните энтити `ix_ads_faction1_terminal` для первой фракции
   - Спавните энтити `ix_ads_faction2_terminal` для второй фракции

3. **Настройка доступа:**
   - Отредактируйте `sh_airbrop.lua`
   - Укажите правильные `factionID` для каждого терминала (одну фракцию или массив)
   - Укажите `allowedTargetFactions` - фракции игроков, которых можно выбирать как цель
   - **Флаги НЕ используются!** Доступ только по фракции персонажа

### Для игроков

1. Подойдите к терминалу своей фракции
2. Нажмите `E` для взаимодействия (появится RP отыгрывание)
3. Через 3 секунды откроется UI с выбором:
   - **Тип вызова:** На позицию или на игрока
   - **Тип аирдропа:** Список доступных аирдропов
   - **Цель:** Заготовленная позиция или игрок из списка
4. Нажмите "Вызвать аирдроп"

### Вызов на позицию
1. Выберите "На позицию" в типе вызова
2. Выберите одну из заготовленных позиций из выпадающего списка
3. Подтвердите вызов
   
**Позиции настраиваются администратором** - игроки не могут выбирать произвольные точки на карте.

### Вызов на игрока
1. Выберите "На игрока" в типе вызова
2. Выберите игрока из выпадающего списка (только игроки из разрешенных фракций)
3. Подтвердите вызов

## Система доступа

**Плагин НЕ использует флаги!** Весь доступ основан на фракции персонажа:

1. **Доступ к терминалу:** Персонаж должен принадлежать к фракции, указанной в `factionID` терминала
2. **Выбор игрока как цели:** Игрок должен быть из фракции, указанной в `allowedTargetFactions`

### Примеры:

**Одна фракция на терминал:**
```lua
faction1 = {
    factionID = FACTION_CITIZEN,  -- Только граждане могут использовать терминал
    allowedTargetFactions = {FACTION_CITIZEN, FACTION_MEDIC},  -- Можно вызывать на граждан и медиков
}
```

**Несколько фракций на один терминал:**
```lua
faction1 = {
    name = "Коалиция",
    factionID = {FACTION_CITIZEN, FACTION_MEDIC, FACTION_ENGINEER},  -- Три фракции могут использовать этот терминал
    allowedTargetFactions = {FACTION_CITIZEN, FACTION_MEDIC, FACTION_ENGINEER},
    positions = { ... }
}
```

Это полезно, когда несколько фракций работают вместе и должны иметь доступ к одной консоли.

## Технические детали

### Сетевые сообщения
- `ADS_OpenTerminal` - открытие UI терминала
- `ADS_RequestAirdrop` - запрос на вызов аирдропа
- `ADS_GetPlayerList` - запрос списка игроков
- `ADS_PlayerListResponse` - ответ со списком игроков

### Функции плагина

```lua
-- Проверка лимита аирдропов
PLUGIN:CheckAirdropLimit(airdropType, faction)

-- Получение данных аирдропа
PLUGIN:GetAirdropDataByType(faction, airdropType)

-- Создание аирдропа
PLUGIN:CreateAirdrop(airdropType, position, faction, spawner)

-- Проверка кулдауна
PLUGIN:CheckCooldown(player, faction)

-- Проверка доступа игрока
PLUGIN:CanPlayerAccessFaction(player, faction)

-- Получение доступных аирдропов
PLUGIN:GetAvailableAirdropsForPlayer(player, faction)
```

## Особенности

1. **Автоматическая парашютная система** - аирдроп спавнится высоко и падает с парашютом
2. **RP отыгрывание** - 3 секунды подключения к терминалу с уведомлениями
3. **Система уведомлений** - окружающие игроки видят кто вызвал аирдроп
4. **Проверка доступа** - на основе флагов и фракций
5. **Лимиты** - контроль количества активных аирдропов каждого типа
6. **Автоудаление** - аирдропы удаляются через заданное время

## Кастомизация

### Добавление нового типа аирдропа

В `sh_airbrop.lua` добавьте в массив `airdrops` нужной фракции:

```lua
{
    type = "medical_supply",
    name = "Медицинский аирдроп",
    description = "Медикаменты и припасы для лечения",
    entityClass = "sw_airdrop_v3",
    maxActive = 2,
    spawnHeight = 800,
    lifetime = 1200
}
```

### Добавление новой фракции

Добавьте новую фракцию в `factions`:

```lua
faction3 = {
    name = "Третья фракция",
    flag = "C",
    allowedPlayerFlags = {"C"},
    airdrops = { ... }
}
```

И создайте терминал `ix_ads_faction3_terminal.lua` по аналогии.

### Изменение внешнего вида терминала

Измените модель в энтити терминала:

```lua
self:SetModel("models/props_combine/combine_interface001.mdl")
```
