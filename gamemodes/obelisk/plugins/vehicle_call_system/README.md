## 🚀 Основные возможности

Полноценный плагин для вызова воздушной и наземной техники в Garry's Mod на фреймворке Helix. Включает терминалы, систему логирования и полное RP отыгрывание всех действий.

### ✨ Ключевые функции:
- **🏢 Терминалы**: Стационарные консоли для вызова техники
- **🔒 Система доступа**: Доступ только через флаг "V"
- **📊 Система лимитов**: Контроль количества активной техники
- **⏱️ Кулдауны**: Защита от спама вызовов
- **📝 Логирование**: Полная история всех действий
- **🎭 RP интеграция**: Реалистичное отыгрывание действий

### 🎯 Типы устройств:
1. **Терминалы** - стационарные консоли (кулдаун 30 сек)

### 🔑 Система доступа:
- **Флаг "V"**: Доступ к системе вызова техники
- Только игроки с флагом "V" могут использовать терминалы
- Флаг можно выдать/забрать через админ-панель или команды

## 🔑 Управление доступом

### Флаг "V" - Доступ к системе вызова техники

Система использует флаг "V" для контроля доступа к терминалам вызова техники.

#### Выдача флага:
```lua
-- Через код
player:GetCharacter():GiveFlags("V")

-- Через консоль (админы)
!flag [имя_игрока] V
```

#### Забирание флага:
```lua
-- Через код
player:GetCharacter():TakeFlags("V")

-- Через консоль (админы)
!unflag [имя_игрока] V
```

#### Проверка флага:
```lua
-- Через код
local hasAccess = player:GetCharacter():HasFlags("V")
```

### Принцип работы:
- **С флагом "V"**: Игрок может использовать все терминалы и вызывать любую технику
- **Без флага "V"**: Игрок не может взаимодействовать с терминалами
- **Админы**: Могут выдавать/забирать флаги через консоль или админ-панель

## 🎮 Использование

### Терминалы:
1. **Убедитесь, что у вас есть флаг "V"** (доступ к системе вызова техники)
2. Подойдите к терминалу
3. Нажмите [E] для взаимодействия
4. Выберите технику из списка
5. Выберите позицию спавна
6. Нажмите "ВЫЗВАТЬ ТЕХНИКУ"

**Примечание**: Если у вас нет флага "V", терминал не будет реагировать на взаимодействие.
